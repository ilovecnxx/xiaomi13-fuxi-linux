# Clash/Mihomo 手机代理客户端 — 交付记录（2026-10-30）

用户需求：手机上安装“类似 Clash 的图形代理客户端”，实在不行就原生移植。

## 结论

- 不需要移植。Mihomo（Clash.Meta）有官方 `linux-arm64` 静态二进制（v1.19.33），
  直接用；GUI 用手机系统自带 GTK4 + libadwaita + PyGObject 原生编写（`work/mihomo-gui/app/clash_fuxi.py`）。
- 已部署到手机并实测通过（HTTP/SOCKS 混合代理链路正常，API 正常，GUI 窗口正常渲染）。
- **TUN 透明代理**受限于当前内核：缺 `CONFIG_IP_ADVANCED_ROUTER` 等策略路由/nft 选项，
  报 `operation not supported`。已从源码编出补好选项的新镜像 `work/kbuild/abl-fuxi-net1.img`，
  用户选择**先不刷机**，因此当前以 HTTP/SOCKS 系统代理模式使用；TUN 待刷入该镜像后可用。

## 手机上已部署（rootfs 增量，仅新增）

| 路径 | 内容 |
|---|---|
| `/usr/local/bin/mihomo` | v1.19.33 arm64，`setcap cap_net_admin,cap_net_raw+ep` |
| `/usr/local/bin/clash-fuxi` | GTK4/libadwaita GUI |
| `/usr/share/applications/clash-fuxi.desktop` | Phosh 应用列表图标 |
| `~fuxi/.config/autostart/clash-fuxi.desktop` | 登录自启 |
| `~fuxi/.config/mihomo/config.yaml` | 默认配置（mixed-port 7890, controller 9090, geodata-mode） |

新增 apt 包：`gir1.2-gtk-4.0` `gir1.2-adw-1` `gir1.2-graphene-1.0` `nftables`（均 additive）。

## 实测

- `mihomo -v` → v1.19.33 linux arm64。
- 内核启动后 7890/9090 正常监听；`http://gstatic.com/generate_204` 经代理返回 204。
- `/version` `/configs` `/connections` API 正常；GUI process 存活、截图非空白（1080×2400）。
- 启动陷阱修复：v1.19 首次启动会下载 geoip.metadb，若中途被杀会残留损坏文件导致每次启动卡住。
  GUI `ensure_dirs()` 现在会清理 <1MB 的残缺 metadb，配置默认 `geodata-mode: true` 规避 MMDB 依赖。

## TUN 内核需求（FUXI_NET=1）

`scripts/fuxi-build-abl.sh` 新增 `FUXI_NET=1` 开关，叠加：
IP_ADVANCED_ROUTER / IP_MULTIPLE_TABLES / IP_ROUTE_MULTIPATH / NF_TABLES_NETDEV /
NFT_NAT / NFT_MASQ / NFT_REDIR / NFT_SOCKET / NFT_TPROXY / NETFILTER_XT_MARK / NET_CLS_ACT / NET_SCHED。

构建产物：`work/kbuild/abl-fuxi-net1.img`（10.4MB，基于 r120idle-mic-rupdclk-audio-disp 变体）。
刷新到 recovery_b 后即支持 TUN，可用 `scripts/fuxi-test-recovery.sh work/kbuild/abl-fuxi-net1.img '<命令>'`。

## 回滚

只删新增文件即可完全恢复；不改动内核/分区。GUI 内 TUN 开关在旧内核下会失败并提示需 FUXI_NET 镜像。

## 2026-10-30 追加：UI 重做为单屏分栏（Clash Meta 风格）

按用户要求美化简化、收敛到一屏，采用类似 Clash Meta 的分栏。新布局：
顶部 HeaderBar → ① Hero 卡（大电源按钮 + 实时上下行速率）→ ② 模式分段（规则/全局/直连，Adw.ToggleGroup）→ ③ 两列开关（TUN | 系统代理）→ ④ 订阅输入行。
实测 `[ui] window 432x960 fullscreened=True`（= 满屏），一屏无滚动。

注：本机 grim 截图在 freedreno + scale=2.5 下抓帧异常（Epiphany 同样只在中央窄带出现），**不能用于判定布局**，验收以目视为准。
