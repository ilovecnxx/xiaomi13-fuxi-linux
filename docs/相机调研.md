MCLK 19.2 MHz。传感器型号/I2C 地址不在 DTB 里（在 Android 用户态的 sensor module 二进制里）。

## 主线现状

- `sm8550.dtsi` 有 camcc（`SM_CAMCC_8550`，已开）、cci0/1/2、`qcom,sm8550-camss`（CSIPHY/CSID/VFE，驱动已支持 SM8550）。
- 主线 cci1 只描述了主机 0；本机前摄在 cci1 主机 1（AON CCI 引脚），已在 camera.dtsi 里补 `i2c-bus@1`。
- 主线 DTS 从 MTP 抄来的几路 LDO 电压与本机相机不符（L1M/L2M 1.104、L4M/L7M/L14B/L16B 3.104、L11B 1.056），camera.dtsi 里按厂商改；
  PM8550VS 的 L1C/L2C 主 DTS 没写，补上（cmd-db 有 ldoc1/ldoc2）。
- 传感器驱动：主线 `drivers/media/i2c` 没有 IMX800 级别的大底传感器；有 ov13b10/ov08x40/s5kjn1/gc08a3 等，要先确认型号。

## 第一步（已实现，待上机）

- 测试驱动 `drivers/misc/fuxi-camera-power.c`（`CONFIG_FUXI_CAMERA_POWER`，checkpatch 0 警告）：
  `xiaomi,fuxi-camera-power` 节点按 `supply-names` 顺序上电、开 MCLK、解除复位，sysfs `power` 开关。
- DTS `sm8550-xiaomi-fuxi-camera.dtsi`（+ 变体 `.dts`）：4 个上电节点、4 个 GPIO 电源开关、MCLK/AON CCI 引脚、cci0/cci1。
- 构建：`FUXI_DTB=sm8550-xiaomi-fuxi-camera scripts/fuxi-build-abl.sh camera1`（临时开 I2C_QCOM_CCI、I2C_CHARDEV、FUXI_CAMERA_POWER）。
- 上机：`scripts/fuxi-camera-probe.sh`：逐个上电，扫 CCI 总线，读索尼 0x0016 / 三星 0x0000 / 豪威 0x300a / 格科 0x03f0 的 ID。

## 补充（10-28）

- **传感器型号已从 Android 模块库文件名确认**（`work/device-info/camera/android-modules.txt`，探测第 0 步拉取的 `.so`）：
  - cam0 主摄 = 索尼 **IMX800**（`semco_imx800_wide` / `sunny_imx800_wide_ii`）
  - cam2 超广角 = 豪威 **OV13B10**（`ofilm_ov13b10_ultra`）——主线已有 `ov13b10` 驱动，可直接接
  - cam1 前摄 = 豪威 **OV32C**（`sunny_ov32c_front`）
  - cam3 长焦 = 三星 **S5K3K1**（`semco_s5k3k1_tele` / `_tele_ii`）
  - 完整模组清单（actuator/OIS/EEPROM）：IMX800 马达 AK7314 + OIS BU24721 + EEPROM P24C128F/GT24P256F；
    S5K3K1 马达 AK7314 + OIS BU24618/BU24721 + EEPROM P24C64F；OV13B10/OV32C EEPROM GT24P64E。
- 上电读 ID 第一步踩了 `fuxi-camera-power` 的 sysfs 命名冲突：`DEVICE_ATTR_RW(power)` 的 `power` 与
  PM core 每个设备自带的 `/sys/.../power` 目录重名 → `device_add_groups()` 失败、开关没建出来。
  已把属性改名为 `power_on`（驱动 + `fuxi-camera-probe.sh` 同步改），重编 `camera3`。
- camera3 上电测试：`power_on` 开关已正常（命名冲突已解），但 `clk_prepare_enable(MCLK)` 报 `-16`，
  dmesg：`cam_cc_mclk1_clk status stuck at 'off'`（`clk-branch.c` 警告）——camcc 的 MMCX/MXC 电源域或
  MCLK 父时钟（bi_tcxo）没真正跑起来，分支门控状态位翻不动。属相机第二步（接 CAMSS 前）要解决的时钟问题；
  传感器型号已从文件名确定，不阻塞型号确认。
