# DSH 手机移植 —— DeepSeek 安卓风界面（2026-10-30）

目标：在 Xiaomi 13（fuxi，**Ubuntu 26.10 arm64 主线 Linux**）上运行 DeepSeek Harness，
手机桌面出现“DeepSeek”App 图标，点击后以**独立原生窗口**打开界面，界面模仿 DeepSeek 安卓端。
**不是安卓 APK**；DSH 引擎是 Node.js，跑在手机的 Ubuntu 上。

## 方案

- 手机端：apt 安装 Node.js 24（arm64），`npm install -g @deepseek-ai/dsh@0.2.1-rc.5`（固定版本）。
- 服务：**用户级 systemd**（`systemctl --user`，无需 root/polkit），由
  `~/.local/bin/dsh-web-launcher` 启动 `dsh --profile web --no-open --host 127.0.0.1 --port 3080`，
  并把带 token 的登录 URL 写入 `~/.local/state/dsh-web/url.txt`（30 天签名 cookie，首次打开用）。
- 省电（手机重点）：
  - **按需启动**：服务不设开机自启，点桌面图标才 `systemctl --user start`；空闲时不占内存/电。
  - **闲置自动停**：`dsh-web-idle.timer` 每 2 分钟检查活动戳，闲置 ≥ `IDLE_MIN`（默认 10）分钟自动停服。
  - 停服后 node 进程退出、约 360MB 内存释放。
  - 原生窗口用 WebKitGTK 并关闭硬件合成/动画（`DSH_SKIN_LOWPOWER=1` 默认开）。
- 权限：
  - 装 Node/npm 用 root（apt/全局 npm）。
  - 日常运行/桌面 App 用 `--as` 指定的用户（默认 `fuxi` 普通用户；也可 `--as root`）。
  - 用户级 systemd 的 `HOME`/`XDG_RUNTIME_DIR`/`linger` 均按运行用户处理；桌面 launcher 能跨用户拉起服务。
- 界面/App 形式：
  - 皮肤：不改 DSH 源码，把 `deepseek-android.css` / `deepseek-android.js` 注入
    `@deepseek-ai/dsh-web-frontend/dist/index.html`（注入前备份）。强制深色、DeepSeek 蓝（#4D6BFE）、
    手机单栏、底部药丸输入条、左侧会话栏改抽屉、顶部“☰ DeepSeek”顶栏。
  - App：桌面图标 `dsh-web.desktop`（图标 `dsh-web.svg`）+ `/usr/local/bin/dsh-web-open`，
    **优先 WebKitGTK 原生窗口**（`dsh-web-window.py`，Phosh 原生 GTK 组件，无地址栏）；
    缺 WebKitGTK 时退 `chromium --app`、GNOME Web、默认浏览器。`--native` 强制安装
    `python3-gi gir1.2-webkit2-4.1`。

## 文件

- `work/dsh-phone/deepseek-android.css`：皮肤（颜色令牌 + 手机布局 + 顶栏/抽屉）。
- `work/dsh-phone/deepseek-android.js`：启动脚本（强制深色 + 顶栏/抽屉/遮罩）。
- `work/dsh-phone/dsh-web.svg`：桌面图标。
- `work/dsh-phone/dsh-web-window.py`：WebKitGTK 原生窗口 + 按需拉起 + 低功耗。
- `work/dsh-phone/apply-theme.sh`：手机端幂等注入，改前备份 `index.html.bak.<时间>`。
- `work/dsh-phone/install-remote.sh`：手机端安装/配置（Node、DSH、用户级 systemd、皮肤、桌面图标、权限）。
- `scripts/fuxi-dsh-deploy.sh`：主机一键部署/回滚。

## 使用

```bash
# 部署（USB 网络，手机 10.42.0.2）：
scripts/fuxi-dsh-deploy.sh --native

# 走 WiFi：
FUXI_HOST=10.10.10.43 scripts/fuxi-dsh-deploy.sh --native

# 日常以普通用户 fuxi 运行（默认，推荐；桌面点击即用）：
scripts/fuxi-dsh-deploy.sh --as fuxi

# 日常以 root 运行（单用户/无 fuxi 时）：
scripts/fuxi-dsh-deploy.sh --as root

# 闲置多少分钟自动停服（省电，默认 10）：
scripts/fuxi-dsh-deploy.sh --idle-min 5

# 用 API key（可选，落盘 ~/.config/dsh-web.env 且 600 权限；否则 App 内登录 DeepSeek 账号）：
scripts/fuxi-dsh-deploy.sh --api-key sk-xxx

# 绑定 WiFi IP（默认 127.0.0.1，仅手机本机访问）：
scripts/fuxi-dsh-deploy.sh --bind 10.10.10.43

# 回滚最近一次部署：
FUXI_HOST=10.42.0.2 scripts/fuxi-dsh-deploy.sh --rollback
```

部署后：手机桌面出现“DeepSeek”图标，点开即用（服务按需拉起 + 原生窗口）。
首次若提示 401 认证：SSH 到手机 `cat ~fuxi/.local/state/dsh-web/url.txt`，把带 token 的 URL
一次性打开（之后 30 天内直接用 App 图标）。模型鉴权：App 内 设置→模型 登录 DeepSeek 账号；
或在 `~fuxi/.config/dsh-web.env` 配 `DEEPSEEK_API_KEY` 后 `systemctl --user restart dsh-web`。

## 注意事项

- 皮肤类名依赖固定的前端版本（CSS Modules 哈希类名）。升级 DSH 后需核对
  `deepseek-android.css` 中的类名与顶栏/抽屉行为，重新执行部署即可。
- 默认绑定 127.0.0.1，只允许手机本机访问，避免局域网明文 HTTP 暴露会话。跨机访问再 `--bind <wifi-ip>`。
- 回滚恢复 `index.html` 最近备份、移除系统级与用户级 systemd 单元/启动器/皮肤/状态目录；不卸载 node/dsh 包。
- 不要在手机上额外跑无头 WebKit 抓 DOM 做验证（实测会把手机跑挂/重启）；验证请在真机屏幕上进行。

## Codex 验收整改记录（2026-10-30）

Codex 首轮评为“需修改”，已逐条修复：
- **深色脚本死循环**：`deepseek-android.js` 的 MutationObserver 改为写前比对当前值，且只观察
  `data-ds-theme-source`/`data-ds-dark-theme`，不再自我触发（省电）。
- **API key 泄露**：不再拼进 SSH 命令行；部署端经标准输入传入，手机 `install-remote.sh` 从
  `DSH_API_KEY_IN` 读，写入 `~/.config/dsh-web.env`（umask 077）。
- **token 入日志/输出**：部署输出只打印脱敏 URL（`token=****`）与文件路径；完整 URL 仅存手机
  `~/.local/state/dsh-web/url.txt`。
- **回滚不生效**：`--rollback` 分支现在真正通过 SSH 执行回滚脚本，并按 `--as` 用户清理系统级+用户级单元/皮肤/图标/状态目录。
- **闲置误停**：原生窗口打开期间每 60 秒刷新活动戳；关闭时再刷新，避免用户聊天中被停服。
- **端口/绑定不贯穿**：`dsh-web-open` 与 `dsh-web-window` 从配置读 `PORT`；窗口探测同一端口。
- **按需启动自检**：安装末尾自检启动后**自动停服**，回到按需模式，不长期常驻。
- **apply-theme**：幂等判断需同时满足“标记 + 两处引用 + 文件存在”；缺 `</head>` 或复制失败则报错退出；原子替换。
- **chown 失败**：由静默改为显式失败退出。
- 低功耗属性名已更正为 `hardware-acceleration-policy`（实测该 WebKitGTK 支持）；设置失败不影响使用。

仍待真机目视验收：屏幕上的深色单栏/顶栏/抽屉外观、登录后实际对话。

## 方案变更：改用「原版 UI + 前台 Chromium --app」（2026-10-30）

原因：原「原生 WebKitGTK 窗口 + DeepSeek 安卓皮肤」方案的皮肤类名绑定 dsh-web-frontend 版本，
升级后易失配；且注入 dist 会被 DSH 更新覆盖，违背“不影响 DSH 更新”。改用：

- **UI**：DeepSeek Harness **原版界面**，不再注入任何皮肤（已从 dist 剥离皮肤、恢复原版 index.html）。
- **窗口**：桌面图标 `/usr/local/bin/dsh-web-open` → **前台 Chromium `--app=URL`**（无地址栏，像 App），
  Chromium 有 GPU 加速（`--use-gl=angle --use-angle=gl --enable-gpu-rasterization`），比 WebKit 软件渲染流畅。
- **Chromium 私有库**：`/opt/chromium` 部署需 `LD_LIBRARY_PATH=/opt/chromium/privatelib:/opt/chromium/root/usr/lib/chromium`，启动器已内置。
- **会话环境**：启动器补全 `XDG_RUNTIME_DIR/WAYLAND_DISPLAY/DBUS_SESSION_BUS_ADDRESS`，保证从桌面点击能弹窗。
- **省电**：仍是用户级 systemd 按需启动 + 闲置自动停（timer）。
- **不影响更新**：皮肤已彻底移除，`npm install -g @deepseek-ai/dsh@新版` 即得新版原版 UI，无需重贴/适配。
- **代理加速更新**：手机可经反向隧道用主机代理装包：
  `ssh -R 7897:127.0.0.1:7897 root@手机`，手机 `npm_config_proxy=http://127.0.0.1:7897 npm install -g @deepseek-ai/dsh@版本`。
- 原皮肤方案文件保留在 `work/dsh-phone/legacy-android-skin/`，可随时恢复。
