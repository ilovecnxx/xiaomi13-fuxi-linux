   证书库有 120 个 CA，正常 TLS 校验下访问 example.com 与 Ubuntu ports 均返回 200。
   没有关闭证书校验或导入自签名证书。本次网络走 USB，共享联网不等于 WiFi 已验收。

   Mesa/EGL 无渲染设备错误。`GSK_RENDERER=cairo` 配合
   `WEBKIT_DISABLE_COMPOSITING_MODE=1` 后浏览器持续运行并实际显示 HTTPS 网页。
   这验证了可用的软件渲染规避路径，尚未通过调用栈定位具体非法指令。

   中文名称和各启动动作。通过 Gio 确认实际解析到覆盖项，并用该启动项重新打开 Ubuntu HTTPS 页面。

   随后确认 **“已输入并保存”**。此前回读 `/home/fuxi/Documents/基本功能测试.txt` 得到
