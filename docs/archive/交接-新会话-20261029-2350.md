## 1. 项目目标与技术栈

**目标**：在 Xiaomi 13（fuxi，SM8550）上运行主线 Linux 7.3 + Ubuntu 26.10 + Phosh，达到日常可用，不使用 vendor kernel/Halium/HAL。
推进顺序：显示/触控/桌面 → WiFi/蓝牙/USB → 音频/通话 → 供电/温控 → 相机/媒体。M5 验收标准见 `docs/目标-M5.md` 开头。

**启动链**：ABL → `recovery_b`（boot.img v1：Image.gz + 厂商 DTB 作诱饵）。`CONFIG_FUXI_FORCE_BUILTIN_DTB` 让内核改用内建的主线 DTB，
**cmdline 取自该 DTB 的 `/chosen/bootargs`**。内建 initramfs 8 秒后 switch_root 到 `linux` 分区 sda33（Ubuntu 26.10 stonking）。
普通开机进入 Android 16（Xiaomi OS3.0.307.0，slot `_b`）。

**内核树**：`build/linux/`，HEAD `5b0764a53`（drm-next 2026-10-21），**52 个未提交改动/新文件**，绝对不要 reset/checkout。

**工具与命令**
- adb：`tools/platform-tools/adb`（PATH 中没有 adb/fastboot）。
- 构建：`FUXI_DTB=<dts名> [FUXI_SUSPEND=1] scripts/fuxi-build-abl.sh <名字>` → `work/kbuild/abl-fuxi-<名字>.{img,config,dtb,build.json}`；
  变体名以 `-audio-disp` 结尾才会套用显示和音频配置；构建结束后恢复主 `.config`。
  **`FUXI_SUSPEND=1` 是本会话新增的开关**，可以在任意变体上加 `-e SUSPEND -e PM_SLEEP`。`*-sleep` 变体会顶掉 audio-disp 配置，不要用它来叠加挂起。
- 刷机：`FUXI_KEEP=1 scripts/fuxi-test-recovery.sh <img> '<ssh 命令>'`。手机要在 Android 下（如果在 Linux，脚本先 ssh 重启回 Android），
  用 adb root 把镜像 dd 进 recovery_b，回读校验后 `adb reboot recovery`。**会重启手机。**
  本会话新增：支持无线 adb（adb root 后端口会变，脚本按 mDNS 重连 `_adb-tls-connect`），支持 `FUXI_HOST=<手机 WiFi IP>` 走 WiFi 做 ssh 检查。
- SSH：`scripts/fuxi-ssh.sh`（USB，手机 10.42.0.2，主机 usb0 10.42.0.1）；`FUXI_HOST=10.10.10.43 scripts/fuxi-ssh.sh`（WiFi）。
- 从 Linux 重启回 Linux：`systemctl reboot --reboot-argument=recovery`；普通 `reboot` 会回到 Android。
- 验收：`scripts/fuxi-health.sh --require-wifi --require-sensors`；主机回归：`python3 -m unittest discover -s scripts/tests`（23:45 实测 42 项 OK）。

## 4. 已解决的问题与仍存在的问题

### 本会话已解决（根因已证实）
1. **CN 下 5 GHz 不可见**：WCN7850 是单 pdev，同时覆盖 5 GHz 和 6 GHz（`supports_6ghz=true`）。`ath12k_regd_update()` 只按 `reg_freq_6ghz` 收窄频率范围，
   CN 没有 6 GHz 规则，范围被压到 2402–2482 MHz。US 有 6 GHz 规则，所以表现正常。修复见第 3 节。
2. **Phosh 选 WiFi 后不弹密码框**：NM 日志 “No agents were available for this request”，原因是缺 secret agent，装 gnome-keyring 后解决。
3. **电池电流符号反了**：小米固件放电时报正值、充电时报负值，与 ABI 相反。依据：接 PC 空闲时读到 −260 mA，同时 charge_counter 在上升；8 核满载时读到 +2271 mA。
4. **battmgr 每 10 s 报 unknown message 0x50**：已静默，#205 开机 45 s 后计数为 0。
5. **SoC 深度睡眠一直为 0**：只有系统挂起才能让 CX 关断。s2idle 一次后 cxsd 计数为 12。
6. **刷机脚本只能走 USB**：已支持无线 adb + `FUXI_HOST`。

### 仍存在 / 未完成
- **s2idle 恢复后管制域回到 US**（#206 验收失败项之一）：修复在 #207 中，未测。
- **手机自 23:41 起连不上**：WiFi ping 不通（ARP INCOMPLETE），adb 和 mDNS 都没有设备，USB 未连接。**原因未确认**。

## 8. 必须遵守的开发要求

- **只写 `linux` 分区（sda33）和 `recovery_b`**。Android 系统和固件分区只读。不回锁，不改 GPT、槽位或 active 位，不碰 `persist`、`modemst1/2`、`fsg`、`fsc`。

- 不读取或输出 WiFi 口令，也不要猜口令。无线和蓝牙地址只存在 `work/device-info/radio-addresses.txt`，不要发布。
