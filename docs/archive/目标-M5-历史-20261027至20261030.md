### M5.3 Phosh 实装 ✅

在 wifi12（simpledrm，无 GPU）上装好了 Phosh，`phosh.service` 已稳定 `active`，进程 phoc/phosh/squeekboard 都在跑。
phoc 用 pixman 软件渲染，`Unknown-1` 输出 1080×2400@60，缩放 2.5；fuxi 用户 PIN 存 `work/state/phosh-pin.txt`。

装机时踩了 4 个缺依赖的坑，已修进 `scripts/fuxi-m5-phosh.sh`：

1. `chvt` 缺失（phosh.service 的 `ExecStartPost=+chvt 7`）→ 加装 `kbd`。
2. 用户会话总线 `/run/user/1000/bus` 不存在 → 加装 `dbus-user-session` + `loginctl enable-linger fuxi`。
3. `gnome-session@.target` 模板缺失 → 加装 `gnome-session-common`。
4. `/home/fuxi/.config` 被 root 建出导致 dconf 写失败 → `chown -R fuxi:fuxi`。
5. **“密码错误”根因：rootfs 制作时 setuid 位丢了**。锁屏认证以 fuxi 身份走 pam_unix → `unix_chkpwd`，
   而 `/sbin/unix_chkpwd`、`passwd`、`su`、`chsh`、`chfn`、`gpasswd`、`mount`、`umount` 全是 755（该 4755），
   非 root 读不到 `/etc/shadow` → 正确密码也报 `authentication failure`。恢复 `chmod 4755` 后，
   `pamtester phosh fuxi authenticate`（fuxi 身份）用 123456 已通过。之前误判的“幽灵触点”其实是这个。

已知非致命小问题：simpledrm 不支持 gamma（`Failed to set gamma`）；缺 gnome-calls/SensorProxy/usbguard 等可选服务。
