## 怎么切换（都不需要电脑）

- **进 Linux**
  - 关机状态：按住 **音量上 + 电源** 开机；
  - 在 Android 里：电源菜单 → 重启 → **Recovery**（LineageOS 需在 开发者选项 里打开"高级重启"）；
  - 电脑上：`adb reboot recovery`。
- **回 Android**：在 Linux 里正常重启（`reboot` / `systemctl reboot`）。
- **进 fastboot**：Linux 里 `systemctl reboot --reboot-argument=bootloader`，或按住 音量下 + 电源。

## Linux 访问方式

- **屏幕**：原生 MSM DSI 面板（1080×2400，60/90/120 Hz），Phosh 走 **GPU 渲染**（Adreno 740，`FD740 (Mesa freedreno, GL 4.6)`，phoc `gles2`）；
  GPU 固件 ZAP 取自 `/odm/firmware`（小米签名）。屏幕键盘为 Stevia；自动亮度、熄屏/唤醒已实测。
- **按键**：电源（`pmic_pwrkey`）、音量下（`pmic_resin`）、音量上（`gpio-keys`，PM8550 GPIO6）。
  电源键暂设为 ignore（`/etc/systemd/logind.conf.d/10-fuxi-powerkey.conf`）。
- **触摸**：ST FTM5（SPI，spi4），主线驱动 `drivers/input/touchscreen/st-ftm5.c`；坐标 1/10 像素（0..10799 × 0..23999），多点。
- **USB 网络**：手机 `10.42.0.2`，电脑 NetworkManager 共享连接 `fuxi-usb`（`10.42.0.1`，自动 NAT）。
- **SSH**：`scripts/fuxi-ssh.sh`（密钥 `work/ssh/fuxi_root`，不随仓库发布）。
- **健康检查**：`scripts/fuxi-health.sh`（失败项必须为 0；加 `--require-wifi --require-sensors` 跑全量）。
- **USB 串口**：`/dev/fuxi-acm`，root 自动登录（`fuxi-serial-shell.service`）。

## 启动链

```
XBL → 高通 UEFI → ABL（槽位 b）
  正常开机   → boot_b … → Android
  recovery  → recovery_b：boot.img v1，kernel = Image.gz + 厂商 fuxi.dtb（诱饵）
              → 主线内核（CONFIG_FUXI_FORCE_BUILTIN_DTB：忽略 ABL 的 DTB，用内建主线 DTB；
                 cmdline 来自 DTS /chosen/bootargs）
              → initramfs：USB 串口就绪后 8 秒内主机没 `touch /tmp/stay` 就
                 switch_root 进 sda33 上的 Ubuntu（systemd）
```

ABL 必须拿到厂商 DTB：它会把 `dtbo` 分区的 overlay 叠到 DTB 上，叠到主线 DTB 会卡死（用"立即 PSCI 复位"的
最小桩内核验证过：附主线 DTB 卡住，附厂商 DTB 19 秒回 Android）。

```
scripts/fuxi-test-recovery.sh work/kbuild/abl-fuxi-<名字>.img '<ssh 命令>' …
#   FUXI_STAY=1：留在 initramfs 串口 shell 执行命令；FUXI_KEEP=1：测完不回 Android

```

## 恢复原厂

- recovery：`backups/20261024-172623/recovery_b.img`（与设备原内容 sha256 一致）写回 `recovery_b`；
- 槽位 a：`boot_a` 已写回原厂（sha256 `c02adcce…`）。`fastboot set_active a` 曾把 50 多个分区
  （abl/tz/hyp/aop/modem/uefi…）的 active 位一起切换；不要自己改 GPT 槽位属性。

## 已知坑

- 内核 cmdline 现由 DTB `/chosen/bootargs` 决定；当前基线已去掉 `*_ignore_unused`，含 `fw_devlink.sync_state=timeout deferred_probe_timeout=30`。
- 内核 cmdline **不要加 `console=ttyGS0`**：/dev/console 变成 USB 串口，主机没读时写满阻塞，启动卡几分钟、关机永远卡住。
- ABL 一次失败启动后，同一 fastboot 会话里拒绝后续镜像：先 `fastboot reboot bootloader`。
- 电脑 USB：`usb1-port6` 过流历史；出现 `error -71`、只能 full-speed 时是线材/接口信号问题，换线。
  `scripts/udev/52-fuxi-usb-port-power.rules` 允许脚本"软件拔插"。
- UFS HS-G5 补丁暂缓（`work/patches/pending/`）：在 G5 下 `reboot -f` 曾进 EDL。
- **蜂窝实验注意**：手机上的 ModemManager 是补丁版（`/usr/local/lib/fuxi-mm/src/ModemManager`），
  另有 `fuxi-modem-keeper.service`；这些是实验产物，恢复日常基线时不需要，也不要据此判断日常状态。
- 刷机/重启前先确认当前设备状态（用户约定：自主刷机需明确许可）。
