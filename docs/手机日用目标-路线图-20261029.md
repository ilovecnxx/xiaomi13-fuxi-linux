# Xiaomi 13 fuxi Linux 日用目标路线图

**目标**

把 Xiaomi 13（fuxi）逐步完善为可稳定日常使用的 Linux 手机。以源码和实测证据驱动修复，保留可回退镜像；不为收集重复反馈而频繁刷机。每个里程碑先完成构建、静态检查和回归准备，再集中做一次设备验收。

**验收阶段**

1. **启动、显示与触控**：冷启动和重启稳定；屏幕无花屏、条纹、错位、黑屏、闪烁或卡死；亮度可调；触控坐标和旋转正确；锁屏、熄屏、唤醒稳定。
2. **桌面与输入**：Phosh 长时间运行稳定；中文输入、软键盘尺寸、文件打开/保存和常见应用入口可用。
3. **连接与通话基础**：Wi-Fi 保存并自动重连；蓝牙、USB-C、蜂窝网络分别完成驱动和固件验证，再测实际联网、通话/短信及定位。
4. **声音与媒体**：扬声器左右声道映射正确；音量与保护参数安全；麦克风、耳机、通知音和媒体播放可用。
5. **供电、温控与硬件**：电池百分比和充电状态可信；待机耗电与唤醒可接受；温控覆盖 CPU/GPU；逐步补齐相机与传感器。
6. **发布门槛**：完成连续运行、重启与核心功能回归；记录镜像哈希、测试证据和恢复步骤，才将候选升级为日用基线。
