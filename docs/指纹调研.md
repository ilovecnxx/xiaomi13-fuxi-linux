# 小米 13（fuxi）指纹：调研结论

更新：2026-10-27。

- 厂商 DTB：`fingerprint_goodix { compatible = "goodix,fingerprint"; l11c_vdd-supply; reset GPIO41; irq GPIO40 }`——
  只有供电和两根 GPIO，**没有 SPI 节点**：屏下光学指纹（Goodix）的数据接口由 TrustZone（QSEE）独占，
  采图、比对都在可信应用（TA）里做，Android 的指纹 HAL 通过 qseecom 和 TA 通信。
- 主线 Linux：没有 qseecom 用户态接口（主线只把 QSEECOM 用在 UEFI 变量上），也没有 Goodix 这颗的开放协议；
  libfprint 不支持。→ **短期不可行**，不投入。
- 可能的路：(1) 研究 TA 协议并在主线实现 qseecom 通道（工作量大、涉及厂商私有协议）；(2) 用屏幕 PIN/密码代替（Phosh 已支持）。
- 另：同一块板上有 Goodix GT9916（`goodix,gt9916` I2C 0x5d）作为备选触摸 IC，主线 `goodix_berlin` 驱动支持；
  本机实际是 ST FTM5（已驱动）。若遇到装 GT9916 的批次，可加一个 DTS 节点兜底。
