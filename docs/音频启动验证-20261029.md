## 找到并修复的问题

1. **音频变体漏编 I²C 控制器**：只有 CS35L41 codec，没有 `CONFIG_I2C_QCOM_GENI`，
   于是 `880000.i2c` 无驱动，功放不能注册，声卡报 `codec dai not found`。
   在 AUDIO_CFG 中补齐 I2C/GENI/GPI 依赖，并加入构建回归测试。
2. **声道与 DT 接口**：主线 CS35L41 不读取旧 `cirrus,right-channel-amp` 属性。
   新机器驱动按 DT 顺序给 T/B 分配接收槽 0/1；DAI cell 改为 1、引用接口 0，
   将十六进制 unit-address 改正为 `dai@12`（端口号十进制 18）。物理左右仍需听音核实。
3. **原音量限制无效**：`snd_soc_limit_volume()` 用 `max-min` 判断 SX 控件范围，
   但 SX 的 `min` 是环绕寄存器起点、`max` 是步数；本机 0x4cf/0x391 导致原限制被拒绝。
   修正 SX 分支，并让机器驱动传播失败，不再忽略限幅返回值。
   实机上限从 913 降至 816；原 TLV 中 0 为静音，1 为 -102 dB、913 为 +12 dB，
   因此 816 略低于 0 dB，测试值 497 对应 -40 dB。该上限不能代替扬声器保护算法。
4. **混音器访问错误**：simple mixer 名称省略 `Volume` 后缀；原脚本用完整控件名调用 sset 会失败。
   检查和测试统一使用 `amixer -D hw:N cget/cset name=...`，直接访问实际控件。
5. **UCM 错用 WCD 控件**：扬声器变体没有 WCD938x，但旧配置仍创建 Headphones/Mic 以及 HP 控件重映射。
   按实际 `ADC1 Volume` 控件选择 WCD 或 speaker-only 配置；保留原 WCD 实验配置供后续使用。
   部署后通过 `alsaucm set _fboot ""` 刷新生成的控制重映射。
6. **PipeWire 探测时后端未接通**：仅在 Speaker 的 EnableSequence 中打开 MI2S 太晚，
   PipeWire 探测 HiFi 时 PCM 返回 EINVAL。将连接放到 SectionVerb 的 EnableSequence，
   桌面成功创建真实输出；设备启用时仍设置保守音量。
7. **拓扑构建会掩盖失败**：旧脚本忽略 alsatplg 编译错误，可能继续验证旧输出。
   新流程在暂存目录编译、回读，成功后才替换；限制 SD 参数并保留编译日志/哈希。
