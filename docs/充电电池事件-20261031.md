# 2026-10-31 充电/电池事件记录

## 结论（一句话）

手机在 Linux 下接**电脑 USB 口**（SDP，只有 5V/500mA）跑 Denial 源码构建（8 路 clang 占满 CPU，
整机消耗 ~2A），把电池耗到 1% 后关机。**不是神秘故障**：电脑 USB 供不上 2A 负载；PD 快充本身
仍未在 Linux 下验证（一直是待办）。

## 电源数据（03:19–03:21 实测）

- 电池 `qcom-battmgr-bat`：CAPACITY=1、VOLTAGE_NOW=3.53V、TEMP=42.8°C、
  STATE_OF_HEALTH=75、CYCLE_COUNT=1155、MODEL_NAME=`M3_4500mah_67w`（67W 快充电池）。
- USB `qcom-battmgr-usb`：ONLINE=1、VOLTAGE_NOW=4.969V、VOLTAGE_MAX=5V、CURRENT_MAX=500mA、
  CURRENT_NOW=447mA、`USB_TYPE=Unknown`。
- 手机处于 **USB gadget 模式**（`/sys/class/udc/a600000.usb/state = configured`，g_cdc 0525:a4a7）
  —— 即通过电脑 USB 做 SSH 网络，电脑口最多给 500mA。
- 电流方向：qcom_battmgr.c 已打补丁（Xiaomi 固件把放电报成正电流，驱动取负）。构建时 -1.977A（放电），
  杀进程后 +255mA（充电）。

## 结论与后续修复点

1. **电脑 USB 只有 500mA**，只能慢充；要充电必须插 **67W/PD 充电器**。
2. PD 快充协商在 ADSP 固件 `charger_pd` 服务（pmic_glink 协议），内核不参与协商；
   内核配置 `UCSI_PMIC_GLINK`/`TCPM` 均未启用（`/sys/class/typec` 为空），与 PD 充电无关。
3. **待办**：手机充上电、回到 Linux 后，插 67W 充电器实测 `qcom-battmgr-usb` 是否变成
   PD（9V/20V、几 A 输入）；若仍是 5V/500mA 则查 charger_pd/固件。见 `TASKS.md` 下一步。
